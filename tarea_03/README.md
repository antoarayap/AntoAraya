# Tarea 03 

### 1.
Estructuré una cápsula narrativa enfocada en la brecha socioeconómica y el sesgo territorial de los concursos de belleza en Chile, utilizando el Índice de Desarrollo Humano (IDH) Comunal que procesamos en la base grupal.

### 2. Estructura HTML 
Cumplí con todos los requisitos mínimos usando etiquetas estructurales semánticas:
* `<header>` y `<footer>` para los extremos de la página.
* Bloques `<div>` para agrupar las secciones.
* Títulos (`<h1>`, `<h2>`) y párrafos (`<p>`) ordenados.
* Una imagen (`<img>`) para mostrar el gráfico de barras.
* Un link (`<a>`) enlazado al sitio oficial del PNUD Chile.
